## 📖 Introduction

**Oritech Smart Splitter** is an addon mod for [Oritech](https://github.com/Rearth/Oritech) that brings the Smart Splitter block introduced in mod version 2.0.0+ back to 1.21.1.

## 🎮 Game Versions

| Minecraft | Loader |
|-----------|--------|
| 1.21.1 | NeoForge |

## 📦 Dependencies

### Required

- [Oritech](https://github.com/Rearth/Oritech)
